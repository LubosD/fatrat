FatRat apt repository

Ubuntu packages of the FatRat download manager.

Supported releases

Ubuntu 26.10 (stonking) and 26.04 LTS (resolute), amd64.

Installation

sudo install -d /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/fatrat.gpg https://lubosd.github.io/fatrat/fatrat.gpg
echo "deb [signed-by=/etc/apt/keyrings/fatrat.gpg] https://lubosd.github.io/fatrat $(. /etc/os-release; echo $VERSION_CODENAME) main" \
    | sudo tee /etc/apt/sources.list.d/fatrat.list
sudo apt update
sudo apt install fatrat          # desktop version
sudo apt install fatrat-nogui    # headless version + terminal UI

Packages

fatratQt desktop application
fatrat-noguifatrat-nogui (controlled through the web interface) and fatrat-tui
fatrat-commonfiles shared by both (installed automatically)
