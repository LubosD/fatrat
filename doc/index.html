FatRat

FatRat is a free download and upload manager for Linux, BSD and macOS. It downloads over HTTP, HTTPS, FTP and FTPS, downloads torrents and Metalink files, and uploads files over FTP. Every transfer belongs to a queue, which decides where the files go, how fast they may transfer and how many transfers run at once.

Ways to use it

FatRat has three front ends:

  • Desktop: the desktop application, with a tray icon.
  • Web interface: a page in your browser, served by FatRat itself, also on a phone.
  • Terminal: fatrat-tui, which works in any terminal, also over SSH.

You can use them at the same time, all against one running FatRat. On a server, FatRat can run without any window, and you use the web interface or the terminal to control it.

Scripts and other programs can control FatRat through the REST API, and add transfers through the D-Bus interface.

Everything else

  • Watch Folders: add the files you save into a folder to a queue automatically.
  • Drop-box: a small desktop window you can drop links onto.
  • Clipboard Monitor: the desktop application offers to download links you copy.
  • BitTorrent Support: downloading and seeding torrents.
  • Creating Torrents: making a .torrent file from your own files.
  • RSS Integration: downloading new items from RSS feeds, including TV episodes.
  • Scheduler: starting and stopping queues and changing their speed limits at set times.
  • Extensions: Python plugins for sites that need special handling.
  • Writing a FatRat Extension: the plugin API, for developers.
  • Command Line: the options of the fatrat program.
  • D-Bus Interface: adding transfers from scripts on the desktop.
  • REST API: the JSON API that the web interface and fatrat-tui use.
  • Configuration Files: where FatRat keeps its settings and data files.
